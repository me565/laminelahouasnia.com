# laminelahouasnia.com

Personal website of Lamine Lahouasnia, Director of Gen AI at Euromonitor International.

- `src/pages/` — home, About and Writing pages
- `src/content/writing/` — one Markdown file per article
- `npm run dev` to preview locally, `npm run build` to build

See `CLAUDE.md` for how to publish an article and the house rules.
